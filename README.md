# 中国海域三维可视化平台

在线地址：https://sq23127.github.io/

基于 Vue 和 Cesium，可直接查看三维地球、导入处理后的 .ocean / JSON 数据、拖动时间轴和逐小时播放波浪资料。
当前示例波浪为 2026-06-01 00:00 至 2026-07-31 23:00 UTC，共 1464 小时；温度、盐度和海流仍为原始月平均精度。

此仓库仅存放 GitHub Pages 网页构建产物。CDS 下载和原始 NetCDF 处理需要完整版的 Python 服务。
网页已内置开发者提供的 Cesium 地图令牌；卫星影像需要联网，本地基础地球在卫星服务不可用时保留。

开发工程： https://github.com/sq23127/Ocean_project
