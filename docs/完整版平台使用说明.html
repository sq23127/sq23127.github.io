海洋平台完整版使用说明

面向接收者：在自己的 Windows 电脑完成下载、导入处理、加载和可视化播放。

只需直接打开一个网页看数据和播放？请使用另行生成的 海洋可视化平台_双击即用.html，并参考 单文件网页使用说明.html。本页是程序使用说明，不是可视化平台入口。

1. 你收到的是什么？

这是当前 Vue 平台配套的 Windows 64 位本地运行版。交付包包含浏览器页面、本地服务和 Python 科学计算运行环境。接收者不需要另外安装 Node.js、Vue 或 Python。它通过本机浏览器操作，不依赖开发者电脑运行。

请解压整个交付文件夹后运行 OceanPlatform.exe。不要只拿走 exe，也不要在压缩包里直接双击。地图底图与 ECMWF/CDS 下载仍需网络；完整版不等于完全离线数据服务。

2. 第一次启动

  1. 将完整文件夹解压到自己的磁盘，保留其中的 _internal 等全部内容。
  2. 双击 OceanPlatform.exe。浏览器会自动打开带本次访问凭证的本机页面。
  3. 保留程序窗口运行；关闭窗口后本地下载、处理和页面服务都会停止。不要同时启动多个副本。
  4. 界面加载后可直接查看包内的演示数据；也可以打开数据工作台开始自己的任务。

默认本机端口为 8765。端口被占用时，按程序提示处理。不要把本机访问地址发给其他电脑当作网站：每位接收者应运行自己收到的程序。重新启动后请用程序新打开的页面；旧访问凭证会失效。

3. 下载前：配置自己的账户

  1. 在浏览器登录自己的 CDS 账户，在 CDS 官方 API 配置页取得个人访问令牌。
  2. 在对应 ERA5 或 ORAS5 数据集页面接受其数据条款。平台不会代替你接受条款。
  3. 打开数据工作台的账户设置，在遮蔽输入框中填写自己的 CDS 令牌并保存。保存表示写入本机配置，不代表远端许可和数据可用性都已验证；实际下载时会返回服务状态。
  4. 如果地图由你的单位维护，可填写该单位的 Cesium 客户端令牌。它与 CDS 下载令牌是两个不同配置。地图令牌改动后按页面提示重新加载地图。

首次看到 401/403 时先检查账户、令牌和数据条款，勿反复提交相同任务。只查看演示数据或导入已有文件时，无需配置 CDS 下载账户。

4. 流程一：下载 → 自动处理 → 地图显示

  1. 打开数据工作台，选择下载流程。
  2. 选择开始和结束时刻，均按 UTC。北京时间为 UTC 加 8 小时。
  3. 选择温度、盐度、海流或波浪，可选择多种；设置需要的海域范围和网格间隔。
  4. 提交下载处理任务。平台在后台依次下载、解包、读取 NetCDF、裁剪重采样、校验并保存 JSON。
  5. 在任务状态中查看当前阶段和服务日志。CDS 可能排队；“下载中”不代表远端已立即开始传输，不显示虚假的精确百分比。
  6. 处理成功后，数据自动加载到地图。也可从已处理数据列表再次加载；选择显示要素、时间段并播放。

下载原始文件和处理结果保存在本机用户数据目录，不会覆盖程序包内的演示数据。不同任务使用独立目录，避免多批下载互相混淆。每次只运行一个下载/处理任务；需要停止时用取消按钮。

建议第一次先试两天波浪、0.5° 网格。ORAS5 温盐流下载为全球资料，可能很大，处理后才裁剪到选定海域；开始前准备足够磁盘空间和时间。

5. 流程二：导入已有 NetCDF → 处理 → 显示

  1. 在数据工作台选择本地 NetCDF 处理流程。
  2. 选择同一批资料的 .nc、.nc4 或 .netcdf 文件，可多选。浏览器会将它们复制到本机服务的数据目录，原文件不修改。
  3. 选择对应字段、时段、范围和网格间隔，再提交处理。
  4. 等待任务成功，平台自动加载处理结果。处理失败时查看错误，原来成功显示的数据仍可继续查看。

文件需是当前处理器支持的 ECMWF/CF 变量和坐标结构。它不是任意 NetCDF 的通用查看器；陌生变量、不同维度或投影需要开发者适配。手动取得的 ZIP 请先解压，不把 ZIP 当作 NetCDF 导入。

6. 流程三：已有平台 JSON，直接加载

使用地图左侧“导入 多合一”选择处理好的平台 JSON，可直接显示，不再进行 NetCDF 转换。按类别导入时，网格尺寸和范围必须一致；海流 u/v 与波浪所需字段要成对。普通 GeoJSON 或任意 JSON 不能直接代替平台网格数据。

手动导入主要作用于当前页面；希望长期复用的 NetCDF 处理任务结果可从本地数据列表加载。不要把浏览器标签关闭前的临时选择当作永久默认设置。

8. 数据与账户保存在哪里？

默认位置为 %LOCALAPPDATA%\OceanPlatform，即当前 Windows 用户自己的本地应用数据目录。界面会显示实际工作目录。原始资料、处理结果、已处理数据列表和账户配置分开存放，重新解压新程序包不会自动清空这些资料。任务进度与日志仅在本次运行中保留；重启后仍可加载已处理的数据。

不要把整个用户数据目录直接发给别人，其中含个人 CDS 配置。分享成果时只挑选需要的处理 JSON 或按开发者说明制作展示包。程序交付包本身不携带开发者的 CDS 令牌、原始下载目录或虚拟环境。

10. 开发者如何重新交付

修改 Vue 源码后先构建前端，再用工程的打包脚本生成完整 Windows 文件夹；交付整个新文件夹或 ZIP，保留全部运行文件。只给接收者 dist 或单个 HTML，仍然无法提供下载与处理。打包前确认没有把开发机的私人账户配置或用户数据目录加入资源。

这是浏览器界面加本机服务的完整应用：可在别人的电脑独立运行，但下载和远程底图不是离线功能。正式外网多人服务属于另一种部署方式，不能直接复用此仅限本机的服务模式。

说明对应当前完整版开发与打包流程。实际交付需经过构建、功能测试与目标电脑验收；本说明本身不代表远程下载任务已经成功。
