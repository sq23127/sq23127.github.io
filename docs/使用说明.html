OCEAN PLATFORM · VUE 工程版操作指南

海洋可视化平台使用说明

先启动 Vue 页面，再下载或处理需要的数据，最后按已下载时次播放。

前端：Vue 3 + Vite + Cesium；数据处理：Python。只看成果时使用完整 dist 构建目录。

数据与交付说明
新增完整版：接收者需在自己电脑下载、导入处理并可视化时，使用 Windows 完整运行包 OceanPlatform.exe，见 完整版平台使用说明。下文关于 dist、start_platform.py 的静态交付属于仅查看模式；开发入口 platform_server.py 提供本机完整服务。

1. 启动页面

根目录 index.html 是 Vue 开发入口。不能直接双击运行，也不能单独复制给别人。开发时通过 Vite 打开，交付时使用完整 dist 文件夹。

在这台电脑直接查看已有成果

项目已附构建好的 dist。在 PyCharm 运行根目录 start_platform.py，会启动本机服务并打开 http://127.0.0.1:8000/；保留运行窗口，停止即关闭服务。这种查看方式无需 Node。源码或数据更新后，先按第 6 节重新构建，再刷新。

第一次运行工程

  1. 安装 package.json 所要求的 Node.js，当前范围为 ^20.19.0 || >=22.12.0。推荐 Node 22.12 或更新的兼容 LTS；pnpm 11 要求 Node 22 或以上，Node 20.19 系列请选 npm。
  2. 在工程根目录参考 .env.example 建立 .env.local，填写该部署使用的 VITE_CESIUM_ION_TOKEN 和可选的 VITE_APP_TITLE。这是地图客户端配置，不能填 CDS 下载令牌。
  3. 在工程根目录终端安装依赖并启动。
npm install
npm run dev

若使用 pnpm 并有对应版本，推荐按工程锁文件安装：

pnpm install --frozen-lockfile
pnpm run dev

二选一即可。pnpm-lock.yaml 与 pnpm-workspace.yaml 应配套保留：后者包括旧版 Cesium 所需的 zip.js 2.7.34 兼容锁定及 protobufjs:false 构建策略。package.json 也配置了 npm overrides；npm install 不会读取 pnpm 锁。浏览器默认打开 http://127.0.0.1:5173/，启用固定端口检查，端口被占用时会报错停止；关闭占用服务，或显式传入 --port 改端口，并让 Cesium 令牌允许新地址。保留终端运行，日后通常只需 npm run dev。

页面启动后自动读取 public/data/scs_field.json，无需重复手动导入。Cesium 程序资源在本地工程中配套提供，默认底图仍需网络。

如仅收到 dist，无需安装前端开发依赖，按第 6 节通过静态服务打开完整文件夹。账户、环境与给别人使用的详细修改清单见《数据与交付说明》。

2. 下载：输入时间段与数据类型

只看现有数据可跳过本节。需要下载时，先按《数据与交付说明》建立 Python .venv，配置自己的 CDS 账户，并在相关数据集页面接受其条款。令牌配置只在本机 Python 使用，不进入 Vue。

.\.venv\Scripts\python.exe download_data.py --setup

在 PyCharm 运行 download_data.py，无需参数即可中文交互输入；或在工程根目录终端执行：

.\.venv\Scripts\python.exe download_data.py
数据类型：1 温度  2 盐度  3 海流(u/v)  4 波浪  5 全部
输入编号或名称，可多选：波浪
开始时间：2026-06-01
结束时间：2026-07-31

也可直接指定条件，以下命令会实际提交下载：

.\.venv\Scripts\python.exe download_data.py --start 2026-06-01 --end 2026-07-31 --fields 波浪

仅想看请求计划，不联网下载时加 --plan：

.\.venv\Scripts\python.exe download_data.py --start 2026-06-01 --end 2026-07-31 --fields all --plan
选择资料真实时间精度
海温 / 盐度 / 海流ORAS5；海流 u/v 配对，处理时取最浅层月平均
波浪ERA5 WAM：波高 swh、波向 mwd、周期 mwp每小时
全部以上字段分别保留真实精度

支持月份、日期或 UTC 整点，例如 2026-06、2026-06-01、2026-06-01T08:00，包含首尾；只填结束日期时包含当天全部小时。默认保存到 01_data，下载包自动解压，完整已有文件复用，排队与下载状态见终端。

下载区域 --area 北 西 南 东，默认 --area 42 105 0 128，只作用于 ERA5；ORAS5 按覆盖月份下载全球资料。

3. 处理并发布到 Vue 数据目录

build_json.py 递归读取 01_data 的 NetCDF，筛选时间、取表层、统一网格与单位。下面处理当前两个完整月份：

.\.venv\Scripts\python.exe build_json.py --input-dir 01_data --start 2026-06-01 --end 2026-07-31 --frequency hour --step 0.5

在 PyCharm 也可运行此文件，把命令中脚本名后面的参数填入运行配置。默认 hour；默认网格 0.2°，本例明确使用与波浪源网格一致的 0.5°，减少长时段数据量。

产物作用
02_Geojson/scs_field.json处理后的网格时间序列，供校验和存档
public/data/scs_field.json校验通过后默认自动发布，Vue 启动时读取
dist/data/scs_field.json运行前端构建后才更新的正式发布副本
开发环境：看到“数据已校验并发布”后刷新页面。
正式部署：重新运行 npm run build，交付或部署新 dist。Python 不会再改 index.html。

当前波浪应有 1,464 个小时帧：2026-06-01 00:00 到 2026-07-31 23:00 UTC。温盐流各保留六月、七月 2 个月平均时次。hour 不会把月平均补造成小时数据。

只处理精确的起止小时
.\.venv\Scripts\python.exe build_json.py --start 2026-06-01T08:00 --end 2026-06-02T08:00 --frequency hour --step 0.5

包含首尾，共 25 个小时；前提是输入资料包含这些小时。北京时间是 UTC 加 8 小时。

只有 JSON，怎样单独发布
.\.venv\Scripts\python.exe check_json.py 02_Geojson/scs_field.json
.\.venv\Scripts\python.exe pack_json.py --data 02_Geojson/scs_field.json

默认发布到 public/data/scs_field.json。build_json.py --json-only 仅生成处理结果，跳过发布；之后需单独运行 pack_json.py 才改变启动数据。

原 --html 参数已停用，使用 --publish-to public/data/scs_field.json 指定发布路径。新路径若改名，还要修改 src/config.js 中的 dataUrl 或手动导入该文件；只写另一个 JSON 不会让页面自动改读它。

4. 查看、拖动与连续播放

  1. 通过开发或部署网址打开页面，选择温度、盐度、海流粒子、波高或波浪粒子。
  2. 设置开始与结束时间，波浪可精确到 UTC 日期与小时，点击播放。
  3. 拖动整行时间轴可往返预览；拖动暂停自动播放，松手定位所选时刻。也可点击时间轴跳转，聚焦后用左右方向键查看。
  4. 上一帧 / 下一帧逐帧查看；调整速度、正放 / 倒放与循环。不循环时到区间边界停止。
  5. 鼠标在地图上移动查看当前帧数值。右侧当前点数据位于数据信息上方，色标随显示要素更新。

切换要素后时间轴只列出该要素的有效时次；至少 2 个时次才能播放。速度影响切帧间隔，不改变数据实际时间精度。1× 目标约 1.1 秒推进一个时次，设备较慢时等待图层准备完成。

色面切换保留旧画面直到新图准备好，再平滑渐变。粒子保留轨迹并更新向量场。渐变减少闪屏，不增加真实观测；波浪粒子速度是显示参数，不是真实波速。

导入按钮何时用

已有其他处理好的 JSON 时可手动导入。“多合一”替换当前数据集；分类导入按时次合并，要求网格和范围一致。海流 u/v 配对，波浪粒子需波高与波向。手动导入只影响当前浏览器，不会自动写回工程或已部署数据。

5. 画质与流畅度

在显示画质区域选择自动、高清或流畅，并调整图层不透明度。调整后会暂停播放，待重绘完成可继续播放。

设置用法
自动按屏幕选择贴图精度，适合日常查看和连续播放。
高清适合放大观察海岸与颜色分布；若切帧等待明显，改回自动。
流畅减少贴图开销，适合性能有限的设备。
不透明度默认 92%；降低可看到更多底图，适用于温度、盐度、波高色面。

海岸采用独立的 Natural Earth 陆地遮罩，裁剪颜色图层；长时段按需生成并缓存少量贴图，不会一次生成全部 1,464 帧。

画面清晰度不等于数据精度。当前 0.5° × 0.5° 是经纬度格点间隔，约数十公里；不是 0.5 公里。高清和更小的 --step 可改善显示或加密插值，不能恢复原始数据没有的近岸细节。

6. 构建成果，给别人使用

npm run build
npm run preview

构建生成完整 dist。预览默认地址 http://127.0.0.1:4173/。端口占用时会报错停止；关闭占用服务或用 npm run preview -- --port 4174 显式换端口，并同步核对地图令牌允许地址。交付给别人时保留 dist 内全部文件；不能只发送其中的 index.html。

把 dist 放到静态网站，即可通过网址查看。接收机已有 Python 时，也可在 dist 目录运行：

py -m http.server 8000 --bind 127.0.0.1

浏览器访问 http://127.0.0.1:8000/。这仅供当前电脑查看，不是可直接发给别人的公网地址。Cesium 地图令牌允许地址要与真实访问网址匹配。

交付源码时提供 src、public、scripts、package.json、pnpm-lock.yaml、pnpm-workspace.yaml、构建配置和说明；接收方自建 .env.local 与运行环境。仅看成果无需 CDS。数据、地图账户与标题具体要改哪里，见《数据与交付说明》。

Cesium 程序与资源随构建交付，默认网络底图仍需联网。完全离线还要另外配置可用的本地底图。

7. 常见问题

页面空白或资源 404

不要双击开发入口；开发用 npm run dev。构建成果交付完整 dist 并用 HTTP 服务打开，检查 data、assets 和 Cesium 资源目录没有遗漏。

更新数据后还是旧画面

检查 build_json 是否发布到 public/data/scs_field.json，是否误加 --json-only。开发环境刷新浏览器；生产环境重新构建并部署整个 dist，再刷新缓存。

地图无法显示或 401、403

检查 .env.local 中 VITE_CESIUM_ION_TOKEN、地图所需权限、Allowed URLs 和网络。修改环境变量后重启 dev；生产版重新构建。不要把 CDS 令牌填入这里。

播放按钮不可用或温盐流不能每小时变化

先选择要素并确保区间至少 2 帧。现有温盐流是月平均，只能按真实月份播放。波浪若被处理成日 / 月平均，改用 --frequency hour 从原始资料重处理。

下载认证或数据许可失败

使用本人的 CDS 配置，检查 CDSAPI_RC、CDSAPI_URL、CDSAPI_KEY 是否指向旧账户；数据集条款需在官方页面接受。--setup 验证认证，不代替接受条款。

处理没有找到数据或提示冲突

确认 NetCDF 已解包、时间范围正确，--input-dir 指向实际目录。冲突版本要移出整个输入目录；移入子目录仍会被扫描。

Node 或依赖安装失败

在工程根目录操作，Node 满足 package.json 的 engines；pnpm 使用匹配的版本和锁文件。npm 用户用 npm install，不要把 pnpm-lock.yaml 当 npm 锁。
