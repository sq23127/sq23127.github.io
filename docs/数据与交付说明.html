2. 这套平台使用的是什么数据？

目前是 ECMWF/Copernicus 再分析数据的海表可视化。再分析融合模型与观测，用于重建海洋状态；页面上的每个格点并不代表那里有一个实测站。三维地球用于展示位置，当前导出的海洋变量取海表或最浅层。

页面要素 / JSON 字段来源及原始变量单位与含义本项目当前时次
温度 / temperatureORAS5：sosstsst，海表温度℃；输入为 K 时转换为 ℃2026 年 6、7 月，2 个月平均帧
盐度 / salinityORAS5：sosaline，海表盐度PSU，实用盐度同上，2 个月平均帧
海流 / u、vORAS5：vozocrte、vomecrtnm/s；u 向东为正、v 向北为正；流速为 √(u²+v²)。处理时取最浅层。同上，u/v 各 2 个月平均帧，成对使用
波高 / swhERA5 WAM：有效波高m，风浪与涌浪组合的有效波高2026-06-01 00:00 至 2026-07-31 23:00 UTC，共 1,464 个小时帧
波向 / mwdERA5 WAM：平均波向度；用于表达波浪来向，粒子显示时转换为传播方向同上，1,464 个小时帧

来源核对：ERA5 逐小时数据集、ORAS5 月平均数据集。ORAS5 原生为约 0.25° 的三极网格；本项目这次把所有要素统一到 0.5° 经纬度网格。ERA5 波浪下载网格为 0.5°。

47 × 85当前统一网格：47 个经度点、85 个纬度点
0.5° × 0.5°相邻经度、纬度格点的角度间隔
105–128°E · 0–42°N当前处理矩形范围，含中国近海及周边区域

JSON 中有 1,466 个时间记录：1,464 个小时记录放波浪字段，另有 2 个月份记录放温盐流。不能把它说成“所有要素各有 1,466 小时数据”。切换要素后，播放器只列出该要素的可用时次。

本文是当前成果快照。重新下载、处理后，以 metadata.fields、页面日期及 check_json.py 输出为准。处理后 JSON 约 114 MB，以独立文件提供，不再内嵌在 HTML；完整原始资料目录约 3.85 GB，含 ZIP 和解包后的 NetCDF。Vue 工程改变了交付形式，没有改变这批数据本身的时次与网格。

3. 数据网格、小时播放和平滑动画分别表示什么？

空间精度：0.5° 不是 0.5 公里

纬度方向每 0.5° 约 56 km；中国近海纬度范围内，经度方向约 41–56 km。因此当前波浪适合看区域尺度变化，无法凭显示插值还原港口、海湾内部几公里的细节。温盐流本次也已重采样为相同的 0.5° 输出网格。

“高清”把色面贴图和海岸边缘画得更清楚；--step 0.1 会生成更密的输出点，并显著增大文件。两者都不会增加原始波浪数据中不存在的真实细节。

时间精度：逐小时、月平均各自保留

  • 所有下载、处理与页面时钟按 UTC。北京时间为 UTC 加 8 小时，例如 2026-06-01 00:00 UTC = 北京时间当天 08:00。
  • 波浪每小时一帧；现有 ORAS5 温盐流是月平均。把处理参数设成 hour，不会把月平均拆成真实小时变化。
  • 月份标签如 2026-06 表示整个月的平均，原文件中间月份时间戳也不应理解为那一瞬间的观测。
  • 页面播放的是已经下载的历史时段，不会自动获取最新观测。缺失小时不会补造；当前帧缺少某字段时，悬浮框显示“—”。

动画精度：渐变与粒子属于表达方式

两幅数据贴图之间的平滑渐变用于减少闪屏，不新增数据时次。海流粒子用 u/v 驱动，并做显示加速；波浪粒子用波向决定方向，当前 buildWaveUV(0.6) 的速度是显示参数，并非由周期计算的真实波速。粒子轨迹不能直接当作浮标实测轨迹或真实传播距离。数值分析应使用对应字段及时间元数据。

海岸遮罩使用 public/data/land-polygons.json 中的 Natural Earth 1:1,000 万陆地数据，只裁剪色面，不提高海洋数据分辨率。“10m”在该数据系列名称中指 1:1,000 万比例尺，不是 10 米精度。当前遮罩覆盖约 98–146°E、6°S–50°N。

4. 数据流程与 Vue 工程结构

download_data.py → 01_data / NetCDF → build_json.py → 02_Geojson/scs_field.json → 校验并发布 public/data/scs_field.json → Vue 页面读取 → Vite 构建 dist

  1. 下载：波浪按日期、小时和区域获取；ORAS5 按区间覆盖到的月份获取全球资料，海流下载包含深度层。
  2. 读取与统一：递归读取受支持的 NetCDF，筛选时间、裁剪区域、取最浅层，重采样到共同网格，并做支持的单位转换。缺测保留 null；聚合波向使用圆周平均。
  3. 生成并发布：build_json.py 校验后生成 02_Geojson/scs_field.json，默认再发布到 public/data/scs_field.json。index.html 不再保存海洋数据。
  4. 前端加载：Vue 启动后从静态 JSON 加载数据和陆地遮罩；导入按钮仍可读取用户选择的本地 JSON。
  5. 正式发布：运行 npm run build 后，数据与程序一起进入 dist。更新 public 下的数据后，开发页面刷新即可；已部署的 dist 必须重新构建和部署。

使用 Vue 3.5.44、Vite 8.3.5、Cesium 1.118.0，具体依赖以 package.json 和 pnpm-lock.yaml 为准。架构分离后，界面布局、地图渲染与 Python 数据处理可分别维护。框架参考：Vue 官方指南、Vite 官方指南。

JSON 的含义没有改变

JSON 项内容
bounds / nx / ny范围与网格尺寸；每个数组是 ny 行、每行 nx 个值，纬度自南向北、经度自西向东。
frames时间记录，每条含 time 和该时次实际存在的字段。
metadata.fields各字段单位、来源、源 / 输出时间分辨率、时段与帧数。
null缺测值；不能改成 0，0 与缺测的含义不同。

02_Geojson 是沿用的目录名；scs_field.json 是平台网格格式，不是标准 GeoJSON FeatureCollection。分类导入要求范围和网格一致；海流 u/v 要配对，波浪粒子需要 swh/mwd。转换器不是任意 NetCDF 的通用读取器。

只有处理好的 JSON，需要单独发布时运行：

.\.venv\Scripts\python.exe check_json.py 02_Geojson/scs_field.json
.\.venv\Scripts\python.exe pack_json.py --data 02_Geojson/scs_field.json

pack_json.py 默认校验并发布到 public/data/scs_field.json；--out 可指定另一 JSON 路径。旧版独立 HTML 仅保留显式模板兼容模式，不用于日常 Vue 构建，也不能覆盖 Vue 的 index.html。

6. 地图令牌与标题配置

  1. 由平台维护者或接收单位在 Cesium ion 令牌页面创建此应用使用的客户端令牌。
  2. 在项目根目录参考 .env.example 新建 .env.local，按下面格式填入接收方自己的值；示例占位符不能原样运行。
  3. 按实际访问地址配置 Allowed URLs，权限只保留地图展示所需范围。客户端使用最小权限；不要加入账户管理权限。参考官方令牌说明。
VITE_CESIUM_ION_TOKEN=替换为该部署的Cesium客户端令牌
VITE_APP_TITLE=中国海域三维可视化平台

改动后，开发环境停止再运行 npm run dev；正式部署运行 npm run build 并替换完整 dist。只修改服务器上的 .env.local 不会改变已经构建的浏览器程序。

VITE_ 变量会进入浏览器程序。Cesium 客户端令牌因此可被访问者读取，应通过权限、资产范围和允许网址约束；它不是保密的服务器密钥。不要将 CDS 令牌、CDSAPI_KEY 或其他私密账户信息改写为 VITE_ 变量。

只看成果的人无需逐人注册 Cesium，维护者统一提供配置即可。地图服务用量归属于提供令牌的账户，应明确维护人并保留地图署名。本文不包含真实令牌，.env.example 也不应包含真实令牌。

Vue 开发环境

安装 package.json 中 engines 支持的 Node.js。当前工程写明 ^20.19.0 || >=22.12.0；建议使用 Node 22.12 或更新的兼容 LTS。pnpm 11 本身要求 Node 22 或以上；Node 20.19 系列应选择 npm。使用 npm 或 pnpm 任选一套流程，不必混合两种依赖安装方式。

使用锁定版本，推荐 pnpm：准备 package.json 所写的 pnpm 版本后，在工程根目录运行：

pnpm install --frozen-lockfile
pnpm run dev

使用 npm：若接收端只有 npm，可运行以下命令。本工程提供 pnpm-lock.yaml，没有 npm 锁；npm install 会自行解析依赖，不使用 pnpm 锁；package.json 提供对应 npm overrides。pnpm-workspace.yaml 必须随源码交付，其中包含旧版 Cesium 的 zip.js 2.7.34 兼容锁定及 protobufjs:false 依赖构建策略；不能只留下锁文件而遗漏此配置。

npm install
npm run dev

默认访问 http://127.0.0.1:5173/。已启用 strictPort，端口被占用时会报错停止；关闭占用服务，或用 npm run dev -- --port 5174 显式换端口，并让 Cesium 令牌允许新地址。保留终端运行；停止后开发网址不可继续使用。根目录 index.html 应由 Vite 提供，不要直接双击。源码中的组件变更由开发服务器更新；环境变量变更需重启。

Python 环境：仅下载、处理者需要

当前核实机器为 64 位 Python 3.13.9。接收机安装对应 Python 后，在工程根目录执行：

py -3.13 -m venv .venv
.\.venv\Scripts\python.exe -m pip install --upgrade pip
.\.venv\Scripts\python.exe -m pip install numpy pandas xarray scipy h5netcdf h5py "cdsapi>=0.7.7" requests

PyCharm 解释器选择新目录的 .venv\Scripts\python.exe。当前代码用 h5netcdf 读取 NetCDF4/HDF，用 scipy 处理 NetCDF3；仅安装 netCDF4 不能替代这些依赖。图形化 CDS 配置需要 tkinter；没有该模块时可手工配置。

只接收构建好的 dist 时，不需要 Node 与这些 Python 库；可以使用接收单位已有的静态服务器。Python http.server 只是有 Python 时的一种本机查看方式。

8. 对方要下载新数据：配置自己的 CDS

  1. 对方登录自己的 CDS 账户，在 官方 API 配置页取得个人访问令牌。
  2. 在需要的数据集下载页接受其条款；--setup 只验证认证，不代替这一步。CDS 官方安装与使用说明
  3. 没有自定义 CDSAPI_RC 时，在项目目录运行下面命令，向本地遮蔽输入窗口粘贴自己的令牌：
.\.venv\Scripts\python.exe download_data.py --setup

也可在对方的用户目录新建 %USERPROFILE%\.cdsapirc，写入这两行，用本人令牌替换占位符：

url: https://cds.climate.copernicus.eu/api
key: <PERSONAL-ACCESS-TOKEN>
当前代码选择配置文件的顺序说明
1. 环境变量 CDSAPI_RC已设置则使用其指定文件；建议写绝对路径。此时 --setup 提示后返回，不覆盖该自定义文件。
2. %USERPROFILE%\.cdsapirc没有 CDSAPI_RC 且此文件存在时使用。
3. 项目提供的本机备用位置%USERPROFILE%\Documents\Codex\.local-credentials\CDS\.cdsapirc；由程序按当前用户计算，不含固定用户名。

已安装的 cdsapi 还会优先读取环境变量 CDSAPI_URL、CDSAPI_KEY，再从配置文件补足缺失值。换账户后仍用旧配置时，检查终端和 PyCharm 运行配置中的这些变量。不要在日志或交接文档里输出令牌来排查。

不要把原电脑的 CDS 凭据复制给接收者。只使用已经下载好的 NetCDF 或已生成网页时，可以完全跳过本节。

先用独立试验目录验证两天波浪

已下载当前完整资料时，无需重复下载：

.\.venv\Scripts\python.exe build_json.py --input-dir 01_data --start 2026-06-01 --end 2026-07-31 --frequency hour --step 0.5

默认生成 02_Geojson/scs_field.json 并发布 public/data/scs_field.json。开发服务器中刷新页面读取新资料；正式版继续执行 npm run build，再部署新 dist。

三个位置的经纬度顺序

位置顺序示例
下载--area 北 西 南 东--area 42 105 0 128，只影响 ERA5；ORAS5 仍下载全球资料。
处理--bounds 西 东 南 北--bounds 105 128 0 42
Cesium 矩形镜头fromDegrees(西, 南, 东, 北)fromDegrees(105,0,128,42)；通常直接改 src/config.js 的 initialBounds 对象。

例如东海矩形下载用 --area 34 118 24 128，处理用 --bounds 118 128 24 34，src/config.js 的 initialBounds 改为 { west: 118, south: 24, east: 128, north: 34 }。超出当前陆地遮罩范围时，需同步更新 public/data/land-polygons.json。

需求参数说明
下载类型download_data.py --fields 海温,盐度,海流,波浪支持中文、编号和英文；没有 --plan 就实际提交下载。
处理字段build_json.py --fields temperature salinity u v swh mwd mwp英文、空格分隔，和下载类型参数不同。
开始 / 结束--start / --end月份、日期或 UTC ISO 时刻，包含首尾；结束日期包含当天全部小时。
时间精度--frequency hour / day / month / native默认 hour；月平均不会被细分成真实小时。
网格间隔--step 0.5本次成果 0.5°；脚本默认 0.2°。减小间隔会插值并增大数据。
下载 / 处理目录--output-dir；--input-dir / --output默认 01_data；处理输出 02_Geojson/scs_field.json。相对路径以脚本目录为准。
发布到另一 JSONbuild_json.py --publish-to public/data/another.json只改变发布位置；页面仍默认读取 scs_field.json，需同步修改 src/config.js 的 dataUrl，或手动导入另一文件。
只生成处理结果build_json.py --json-only跳过 public/data 发布；页面启动数据不会自动变化。
旧 --html 参数--html 已停用会报出迁移提示，改用 --publish-to；Vue 入口不能作为数据输出。

输入目录递归扫描 NetCDF，不读取尚未解包的 ZIP。冲突版本应移出输入目录，移进其子目录仍会被扫描。

10. 构建、交付与网站部署

开发完成后构建

npm run build
npm run preview

pnpm 用户把 npm 换成 pnpm。构建输出到 dist，预览默认地址 http://127.0.0.1:4173/。端口占用时会报错停止；可关闭占用服务或用 npm run preview -- --port 4174 显式换端口，并同步核对地图令牌允许地址。preview 用于检查构建成果；正式对外访问使用静态服务器。

只发成果：完整 dist，一个文件也不要漏

若接收者使用 PyCharm 或已有 Python，也可把根目录 start_platform.py 放在 dist 同级，运行它打开 http://127.0.0.1:8000/。它仅提供已构建文件，不执行下载或编译。修改数据或源码后，维护者需要先重新构建；启动服务不会自动更新 dist。

交付整个 dist 文件夹，保留其中 assets、data、docs、Cesium 资源等全部内容。不能只复制 dist/index.html，也不能交开发入口代替 dist。接收方将完整文件夹交给其静态服务器，访问 HTTP(S) 地址。

接收机已有 Python 时，可在dist 文件夹打开终端：

py -m http.server 8000 --bind 127.0.0.1

打开 http://127.0.0.1:8000/。这个地址只用于当前电脑；发给别人不会让对方访问到你的电脑。让 Cesium 令牌允许真实使用的地址。

正式网站更新

  1. 在维护者电脑完成下载、处理和校验，确认 public/data 下是要发布的数据。
  2. 配置 .env.local 中的地图令牌、标题及允许地址。
  3. 运行 npm run build，先用 npm run preview 验收。
  4. 把完整 dist 部署到 HTTP(S) 静态网站，更新缓存，使 HTML、程序和数据来自同一版本。

更新 Python 结果不会改动已部署的网站。要重新发布 JSON 到 public/data，重新构建并替换部署内容。不建议让接收者直接修改 dist 的压缩程序。

联网、离线和服务边界

Vue 与 Cesium JS/CSS、Workers、Assets 在构建中配套交付，不再依赖远程 Cesium CDN；海洋数据与遮罩也随包交付。默认底图仍访问网络地图服务，因此不是完全离线地图。真正离线需再准备许可允许的本地底图、替换地图来源并验收。

此版本是静态 Vue 前端 + 本地 Python 工具，没有后端账户系统、服务器下载队列或自动定时更新。页面导入按钮读取用户选中的本地 JSON。若要加这些服务，需要另做后端及前端适配。

公开静态文件可被访问者取得；数据权限不能靠隐藏按钮实现。指定人员访问需由服务器提供访问控制。公开展示时保留 ERA5、ORAS5 数据来源与许可要求；陆地资料为 Natural Earth 公共领域数据。

11. 交付前验收

  • 交付方式明确：只看用完整 dist；开发用源码和锁文件；自行下载才配置 CDS。
  • 接收端安装兼容 Node，依赖安装和 npm run build 成功，源码包保留 pnpm-workspace.yaml；Python 使用其自己的 .venv。
  • .env.local 配置的是此次部署的 Cesium 客户端令牌，地址限制匹配实际网址；CDS 凭据没有进入 Vue 环境变量或静态目录。
  • 通过 HTTP(S) 打开，海洋 JSON 与陆地遮罩正常读取，Cesium 资源完整，底图可显示。
  • 波浪是 1,464 个小时帧，温盐流各 2 个月平均帧，或与接收方新处理的元数据相符。
  • 往返拖动、松手定位、正放、倒放、暂停、循环可用；右侧详情和底部时间控件不互相遮挡。
  • 自动 / 高清 / 流畅画质可切换；用实际长时段数据在接收电脑检查初始加载与切帧。
  • 数据更新后开发页已刷新；正式版重新构建部署，预览显示正确的新时段。
  • 交付包不含个人 CDS 配置、原 .venv、node_modules 或个人 IDE 路径；说明与数据文件一并交付。
